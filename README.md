# João Carvalho · Portfólio de projetos

Desenvolvimento de sistemas, interfaces, automações e estudos de criptografia com Python, Java e TypeScript.

Este portfólio reúne demonstrações documentadas dos meus projetos: o problema abordado, as tecnologias e exemplos de uso. Os exemplos usam dados fictícios; os códigos completos dos projetos apresentados são mantidos em repositórios privados.

[Visitar meu site](https://joao-carvalho.pages.dev/)

## Projetos em destaque

| Projeto | O que apresenta | Tecnologias | Demonstração |
| --- | --- | --- | --- |
| SESlock Holmes · TCC | Observabilidade e investigação de eventos de e-mail | TypeScript, Supabase, PostgreSQL | [Conhecer o projeto](projetos/seslock-holmes.md) |
| Análise de Gastos | Controle de despesas e visualização por categoria | Python, ttkbootstrap, pandas, matplotlib | [Ver exemplo](projetos/dinheirometro.md) |
| Sistema Biblioteca | Cadastro de livros, clientes e reservas | Java, Swing, NetBeans | [Ver fluxo](projetos/sistema-biblioteca.md) |
| Optimus RH · QA | Pré-cadastro, RPA e estrutura de testes unitários, E2E e de integração | Python, Flask, SQLAlchemy, Playwright, pytest | [Ver fluxo e testes](projetos/optimus-rh.md) |
| Cifra_bloco | Estudo de cifra simétrica de 32 bits para arquivos | Python, criptografia, S-box, P-box | [Conhecer o estudo](projetos/cifra-bloco.md) |

O destaque de **QA do Optimus RH** apresenta os casos de teste existentes no código: nove testes unitários de formato e limpeza de CPF, um fluxo E2E com Playwright e um teste de integração da RPA com SQLite em memória. **Cifra_bloco** explica a construção didática da cifra e seu uso pela linha de comando. As páginas documentam o trabalho sem publicar o código dos repositórios privados.

## Como explorar

Cada página mostra um cenário ilustrativo e os limites do projeto. Os diagramas explicam os fluxos; não são capturas das aplicações nem demonstrações interativas. Nenhuma aplicação precisa ser instalada para consultar este material.

## Sobre este repositório

Repositório público de apresentação. Não contém credenciais, dados de clientes, candidatos, despesas pessoais ou o código dos sistemas privados. Os exemplos foram escritos especificamente para o portfólio.
